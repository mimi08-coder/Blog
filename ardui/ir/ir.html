Infrared (IR) Sensor

📌 Table of Contents

  • Introduction
  • Working Principle
  • Structure & Pin Connections
  • Output signals
  • Code

1. Introduction

The infrared (IR) sensor is one of the most common components in robotics, especially in line-following robots. It allows the robot to “see” black or white lines and react accordingly.

Applications of IR Sensors

  • Line-following robots: detecting black lines on white surfaces.
  • Obstacle detection: when an object blocks IR light.
  • Object counting: in production lines.
  • Remote controls: sending signals with IR beams (like TV remotes).

2. Working Principle

An IR sensor consists of two main parts:

  • IR LED: emits infrared light.
  • Photodiode / Phototransistor: receives the reflected light.

Mechanism:

  • On a white surface → strong reflection → sensor detects high signal.
  • On a black surface → absorbs light → sensor detects weak or no signal.

👉 This difference allows the IR sensor to distinguish black vs. white.

3. Structure & Pin Connections

A typical IR sensor module has 3 pins:

  • VCC: Connect to 5V power supply.
  • GND: Connect to ground.
  • OUT: Digital output signal (HIGH/LOW).

Some modules include a potentiometer to adjust sensitivity.

4. Output Signals

Digital IR sensors: OUT gives only 0 or 1.

  • 0 → strong reflection (white).
  • 1 → weak reflection (black).

    • Analog IR sensors: OUT gives a voltage (0–5V), which Arduino reads with analogRead().

5. Code


// Example Code to Read Sensor
int irPin = A0; // IR sensor connected to A0

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = digitalRead(irPin); // read digital signal
  Serial.println(value);          // print to Serial Monitor
  delay(200);
}

👉 If the Serial Monitor prints 0 → white, 1 → black (depending on sensor type).
